# 策略逻辑详解

## 为什么要"1H 滚动合成 4H"？

### 传统 4H K 线的问题

在 Binance 上,4H K 线按 UTC 分桶: `00:00-04:00 / 04:00-08:00 / 08:00-12:00 ...`。
一根 4H K 线只在每 4 小时的第 0 分钟才真正定型,中间 3 小时的波动信息被"揉进"同一根。
这意味着:

- **信号滞后**:真正的金叉/死叉可能已经发生 3 小时,但你要等到整点才会被指标捕获
- **时机尴尬**:如果你的 Routine 在 05:17 触发,用的仍是 04:00-08:00 那根尚未完成的 K 线,它的 close 会随后 3 小时持续变化

### 滚动合成的解法

在任意时刻 T,取 `[T-3h, T-2h, T-1h, T]` 这 4 根 1H K 线合成一根"**滚动 4H**":

- `open` = T-3h 的 open
- `high` = 4 根中的最大 high
- `low` = 4 根中的最小 low
- `close` = T 的 close(即最新收盘价)
- `volume` = 4 根 volume 之和

这根滚动 4H K 线**每小时都会产出一根新的**,让所有基于 4H 的指标(EMA/MACD/RSI/BB/ATR)获得 **1H 的刷新频率**,响应速度提升 4 倍而信号平滑度不变。

### 与 `resample("4H")` 的区别

| | `resample("4H")` | 滑动窗口合成 |
|---|---|---|
| 产出节奏 | 每 4h 一根 | 每 1h 一根 |
| 对齐方式 | 固定 UTC 分桶 | 以当前时刻为右端 |
| 响应速度 | 慢 | 快 |
| 信号一致性 | 每 4h 更新 | 每 1h 更新 |

## 指标组合(6 个维度)

参考 [Freqtrade](https://github.com/freqtrade/freqtrade)、[Jesse](https://github.com/jesse-ai/jesse) 中常见的多指标共振策略,选用六个互补维度:

### 1. EMA20 vs EMA50(趋势跟随)
- **位置分**:EMA20 在 EMA50 之上 → 上升趋势 `+1`;反之 `-1`
- **交叉分**:刚发生金叉 `+1` / 死叉 `-1`
- **强度放大**:|EMA20-EMA50|/close > 1% 时整体乘 1.2

### 2. MACD(12, 26, 9)(动能)
- **MACD vs 信号线**:正差 `+0.5`,负差 `-0.5`
- **柱状图方向**:增大 `+0.5`,减小 `-0.5`
- **零轴穿越**:MACD 上穿 0 轴 `+1`,下穿 `-1`

### 3. RSI(14)(超买超卖)
- RSI < 30 → **严重超卖** `+2`(买入)
- RSI < 40 → `+1`
- RSI > 70 → **严重超买** `-2`(卖出)
- RSI > 60 → `-1`
- 否则 `0`

### 4. Bollinger Bands(20, 2)(位置+波动)
- 价格触下轨(%b < 0.1) `+2`
- 价格接近下轨(%b < 0.3) `+1`
- 价格触上轨(%b > 0.9) `-2`
- 价格接近上轨(%b > 0.7) `-1`

### 5. Volume 确认
- 量 > 1.5×均量 且 价涨 `+2`
- 量 > 1.2×均量 且 价涨 `+1`
- 量 > 1.5×均量 且 价跌 `-2`
- 量 > 1.2×均量 且 价跌 `-1`

### 6. Trend Strength(短期趋势强度)
近 10 根 close 的线性回归斜率归一化:
- 斜率/价格 > 0.5% 每根 → `+2`
- > 0.2% → `+1`
- < -0.5% → `-2`
- < -0.2% → `-1`

## 加权综合评分

```
score = 2.5·ema_cross + 2.0·macd + 1.5·rsi + 1.5·bollinger + 1.0·volume + 1.5·trend_strength
```

理论区间:`[-15, +15]`,实际大多落在 `[-10, +10]`。

### 行动映射(默认阈值)

| Score | Action |
|---|---|
| ≥ +6 | **STRONG_BUY** |
| +2 ~ +6 | BUY |
| -2 ~ +2 | HOLD |
| -6 ~ -2 | SELL |
| ≤ -6 | **STRONG_SELL** |

## 止损/止盈(ATR-based)

基于 14 周期 ATR(波动率)动态设定:

- **多头**:止损 = 入场价 - 1.5·ATR,止盈 = 入场价 + 3.0·ATR (R:R = 1:2)
- **空头**:反向对称

## 调参建议

- **激进派**:把阈值改为 `strong_buy=4, buy=1` → 信号更频繁,胜率略低
- **保守派**:`strong_buy=8, buy=3` → 信号少但更确定
- **不同市场阶段**:
  - 趋势市:加大 `ema_cross` 和 `trend_strength` 权重
  - 震荡市:加大 `rsi` 和 `bollinger` 权重

## 风险提示

1. **过拟合风险**:以上权重和阈值是**行业通用经验值**,未经用户历史回测。上线前强烈建议用 backtrader 或 [vectorbt](https://github.com/polakowo/vectorbt) 对过去 1-2 年数据回测。
2. **黑天鹅**:技术指标对突发消息、黑客、监管政策完全无效。
3. **资金管理**:无论信号多强,**单笔风险不应超过账户 1-2%**,这点比选信号本身更重要。
4. **不要 all-in**:本信号适合作为"参考之一",而非唯一决策依据。

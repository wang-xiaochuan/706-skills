# 四层审视框架

> 706小代笔的审视方法论。不是规则清单——是阅读和判断时运行的思维层次。
> 每次审稿、每次写作自检、每次消化Inbox材料时，四层同时运行。

---

## 框架总览

```
第四层 · 元审视    →  审视自己的审视：盲区？惯常框架？有什么我漏掉的？
  ↑
第三层 · 审美层    →  节奏、质地、留白、声音——文本给读者的"体感"
  ↑
第二层 · 逻辑层    →  论证链、前提、推理——文本的"骨架"是否站得住
  ↑
第一层 · 文本层    →  字词句的准确性——AI腔、宣传腔、语病、翻译腔
```

四层之间是**叠加**关系。文本层的问题可能暴露逻辑层的偷懒（用华丽辞藻掩饰论证缺口）。逻辑层的问题可能在审美层表现为节奏的某种"心虚"（加速跳过薄弱环节）。元审视贯穿全程——我在看这篇文本的时候，我自己的位置是什么？

---

## 第一层：文本层

**审视什么**：字、词、句的选择。这是最表层，也是最容易发现问题的一层。

### 审视维度

#### 1.1 AI腔检测
AI生成的文本有一些可辨识的模式。逐句扫描：

| 症状 | 示例 | 处理 |
|------|------|------|
| 排比句堆叠（3个以上结构相同的句子连续出现） | "它是XX的，它是YY的，它是ZZ的。" | 保留一个，其余改成不同句式 |
| "不仅……而且……""既……又……" | "这不仅是一次聚会，而且是一次思想的碰撞" | 删掉"不仅"，后半句独立成句 |
| "在XX的今天/当下/时代背景下" | "在AI加速的今天" | 删掉，直接说事 |
| 三段式总结收尾 | "总之，这次活动让我们看到了……也让我们相信了……更让我们期待……" | 结尾是一个画面、一个悬而未决的问题、或直接停止 |
| "不是X，而是Y"句式 | "这不是一次普通的聚会，而是一次……" | 说它是什么，不说它不是什么 |
| "值得一提的是/值得注意的是" | | 删掉，直接说值得注意的内容 |
| 过度使用"这"字起句 | "这让我想到……""这不禁让人……""这恰恰说明……" | 连续三句"这"起句=AI腔确认。换句式 |
| 情绪形容词堆叠 | "令人惊叹的""前所未有的""深刻的""巨大的" | 删掉形容词，用事实让读者自己感受 |
| "一方面……另一方面……" | | 如果不是真正对立的两个方面，删掉 |
| "通过……实现了……" | | 改成主动语态的人话 |

**检测方法**：把一段话读出来。如果某一句读的时候嘴不顺、气不对——那大概率是AI腔。

#### 1.2 宣传腔检测

| 症状 | 处理 |
|------|------|
| "我们致力于……""旨在……" | 说你做了什么，不要说你在致力于什么 |
| "具有重要的意义/价值" | 删掉。如果真有意义，读者自己会感受到 |
| "为……做出了贡献" | 改写成具体的人和具体的事 |
| "得到了广泛认可" | 谁的认可？什么形式的认可？写具体 |
| "推动了……的发展" | 推动了什么？怎么推动的？写具体 |

#### 1.3 翻译腔检测

| 症状 | 处理 |
|------|------|
| 长定语叠加（"一个在XX背景下由XX发起的旨在XX的XX"） | 拆成多个短句 |
| 被动语态滥用（"被广泛认为是……"） | 改成主动语态 |
| "性/化/度"滥用（"可操作性""常态化""粘合度"） | 用中文本身的方式说 |
| "作为"起句（"作为一个……"） | 删掉，直接说 |

#### 1.4 语病与不自然

- 主谓宾过长导致读者喘不过气
- 代词指代不明（"他/她/它/他们"——读者不知道在说谁）
- 标点不当（中英标点混用、逗号一逗到底）

### 文本层判断标注

```
✅ 文本层通过：字词句准确、无AI腔、读出来像人话
⚠️ 文本层有问题：[具体位置] + [症状] + [建议改法]
❌ 文本层问题严重：[多处/全段] + [主要症状]
```

## 第二层：逻辑层

**审视什么**：文本的论证结构。不是问"这段话好不好"，是问"这段话站不站得住"。

### 审视维度

#### 2.1 论证链完整性
- 结论有没有被前面的论证支撑？
- 有没有跳跃？（A说了，B说了，突然跳到D，C不见了）
- 有没有循环论证？（用结论证明前提）

#### 2.2 前提可靠性
- 文本依赖什么前提？（显性的和隐性的）
- 这些前提本身可靠吗？需要被论证吗？
- 有没有偷换前提？（开头说的是A，论证过程中悄无声息地换成了B）

#### 2.3 证据质量
- 引用的证据（数据、引语、案例）是否准确？
- 证据和结论之间的连接是否合理？
- 有没有以偏概全？有没有幸存者偏差？

#### 2.4 回避与省略
- 论证链条中哪里"跳过去了"？
- 什么关键问题被回避了？
- 有没有用修辞（煽情、排比、反问）替代论证？

### 逻辑层判断标注

```
✅ 逻辑层通过：论证链完整、前提可靠、证据扎实
⚠️ 逻辑层有问题：[位置] + [什么问题] + [建议]
❌ 逻辑层问题严重：[主要问题]
```

## 第三层：审美层

**审视什么**：文本给读者的"体感"。不是文笔好不好看——是读者在阅读过程中的身体感受：哪里流畅、哪里卡顿、哪里喘不过气、哪里走神了。

### 审视维度

#### 3.1 节奏
- 全文的疏密分布是否合理？
- 有没有连续几段都是"密"（信息密集、句子长）让读者累？
- 有没有连续几段都是"疏"让读者走神？
- 段落长度的变化是否有意图？（全篇每段3-5行=节奏单一，像模板）
- 有没有短到只有一句话的段落？（好的短段是节奏中的"呼吸点"）

**检查方法**：扫一遍每段的字数。如果每段字数差不多，节奏可能太均质了。

#### 3.2 质地（具体 vs 抽象的比例）
- 全文中具体的画面、对话、数字、物件的比例是多少？
- 抽象概括和具体的"锚点"之间的比例是否失衡？
- 每一段抽象论述之后，有没有一个具体的东西让读者"着陆"？

**经验法则**：如果连续两段以上全是抽象概念、没有具体物——读者会开始漂移。需要插入一个画面或一个具体案例。

#### 3.3 留白
- 文章有没有给读者"停顿"的空间？
- 有没有把每件事都解释到头？（过度解释=不信任读者的理解力）
- 段落之间有没有呼吸？（空行不是留白。留白是内容本身的空隙——作者选择了不填满）

#### 3.4 声音
- 读出来是什么感觉？像一个人在说话，还是像一个机构在发布？
- 叙述者的位置是否清晰？（读者知道"谁在说"吗？）
- 声音在全文中是否一致？（不能前半段唠家常、后半段突然变成学术报告）

#### 3.5 开篇与收尾
- 开篇是把读者拉进来的，还是在"交代背景"？
- 收尾是自然收束的，还是在"总结升华"？
- 收尾有没有留一个具体的、悬在空中的东西？

### 审美层判断标注

```
✅ 审美层通过：节奏有变化、具体抽象比例合理、有留白、声音一致
⚠️ 审美层有问题：[维度] + [具体位置] + [建议]
❌ 审美层问题严重：[主要维度]
```

## 第四层：元审视

**审视什么**：审视自己的审视。这一层不评判文本——评判评判本身。

### 审视维度

#### 4.1 盲区检查
- 我正在用我熟悉的框架套一个我不熟悉的文本吗？
- 我对这篇文章的判断，有多少是我自己的品味偏好在起作用？
- 我有没有因为某种"应该怎样写"的预设而漏掉了这篇文章真正在做的事？

#### 4.2 位置检查
- 我作为审视者，站在什么位置？（同代人？外行？同领域的竞争者？）
- 这个位置给我的审视带来了什么优势和局限？
- 如果换一个位置（比如目标读者的位置），我的判断会不会不同？

#### 4.3 过度审视风险
- 我是不是在为了用框架而用框架？
- 有些文本的问题可能只在某一层——我是不是在"找"其他层的问题？
- 审视的目的是帮助文本变得更好。如果审视本身变成了负担，退一步。

### 元审视标注

```
🔍 元审视：
- 我的盲区可能在于：[……]
- 我的位置带来的局限：[……]
- 我没有过度审视：[是/否，如果否，说明哪里过度了]
```

## 审稿输出模板

对文章（或段落）审稿时，按以下格式输出判断：

```
## 审视：《文章/段落标题》

### 第一层 · 文本层
[逐条列出文本层问题，标注 ✅/⚠️/❌]

### 第二层 · 逻辑层
[逐条列出逻辑层问题，标注 ✅/⚠️/❌]

### 第三层 · 审美层
[逐条列出审美层问题，标注 ✅/⚠️/❌]

### 第四层 · 元审视
[盲区、位置、过度审视风险]

### 总体建议
[基于四层审视的整合建议]
```

短段落可以只展开有问题的层。长篇审稿必须四层全开。

## 自检清单（写作时用）

写每一段时，自问：
1. 这段话读出来像人话吗？（文本层）
2. 这段话的论证站得住吗？（逻辑层）
3. 这段话的节奏对吗？前面太密了吗？这里需要留白吗？（审美层）
4. 我是不是在用惯性写作，而不是在想事情？（元审视）

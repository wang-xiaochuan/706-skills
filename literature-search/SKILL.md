# Literature Search

把"找文献"从一次性的会话工作流，变成可复用、可审计、可追溯的结构化资产。

本 skill 还原自 706 在 2026 年 4–7 月的真实文献检索实践——315 条学术文献综述（OpenAlex 管线）与《大退出》文献调查（WebSearch 快速扫描）两套范式。参考实现位于 `digital-employees/03-research/tools/`，脚本留在原位、不复制进本目录（单一事实源）；本 skill 定义的是方法，脚本是方法的一次实现。

所有项目相对路径以 `$706_LOCAL` 为根；先核对目标路径。上游 WebSearch 指当前宿主可用的网页检索工具。

## 模式选择

| 判断 | 模式 A · 快速扫描 | 模式 B · 结构化数据库 |
|------|-------------------|----------------------|
| 深度 | 按问题补足关键文献线索 | 系统检索、去重、纳入审查与版本留痕 |
| 目的 | 验证判断 + 提供可引用锚点 | 建立可长期增补的文献资产 |
| 数据源 | WebSearch（CNKI 中文 + 英文期刊 + 最新年度） | OpenAlex API + 策展灰色文献 + 人工核验 |
| 产出 | 素材清单 Markdown | 项目字段 CSV 数据库 + 来源登记表 + summary |
| 适用 | 报告写作前补缺口、梳理研究时间线 | 研究项目立项、需要引用密度和可审计性 |

用户说"扫一下文献"默认走模式 A；说"建一个文献库/数据库"或给明确的研究问题要长期跟踪，走模式 B。未指定规模时先按模式 A 推进，并说明范围；只有影响检索边界的关键信息缺失时再询问。

## 模式 A · 快速扫描

### A1. 建关键词矩阵

先按研究问题的维度拆概念群，每个概念群给出中英关键词对与优先级：

| 概念群 | 中文关键词 | 英文关键词 | 优先级 |
|--------|-----------|-----------|--------|
| （维度名） | 断亲、亲缘关系淡化 | family estrangement, kinship disconnection | P0 |

优先级规则：P0 = 报告直接引用的数据点来源；P1 = 论证增强；P2 = 延展阅读。

### A2. 按问题选择检索轮次

1. **中文轮**：CNKI 为主，搜每个 P0 概念群的中文关键词
2. **英文轮**：英文期刊（Google Scholar 摘要可见即可，不追全文）
3. **最新轮**：限定最近 12 个月的发表，专门补时间线上的新鲜文献

以上是可选检索维度，不是固定三轮或计时要求。按主题覆盖、语种和时效补缺；保留检索式、数据库、访问日期和覆盖限制。需要支持具体主张时读取原文相关段落。

### A3. 产出素材清单

根据研究问题产出**关键文献时间线**和必要的**已核验数字表**：

- 关键文献时间线：`| 年份 | 里程碑 | 期刊/来源 |` —— 按时间排列关键文献；选中的搜索结果不足以证明整体关注度上升
- 可引用数字表：`| 数据点 | 数值 | 来源 |` —— 只有能在正文直接引用的数字才进这张表，来源须含作者、年份、原文链接与段落/表格定位；仅有 DOI、期刊名或聚合摘要不等于数字已核验

最后写一段**核心判断**：跨维度看模式（是不是共享同一条时间线？哪里"话语先行于学术"？）。参考实现见 `706-production-research/emerging-social-forms-micro-observations/source/literature-survey-results.md`。

## 模式 B · 结构化数据库

以下三脚本是中国移入人口研究的历史参考实现，位于 `digital-employees/03-research/tools/`。它们含固定查询、输出路径与旧分级规则，不能作为通用命令直接运行，也不要覆盖旧项目产物。新项目应明确输入、输出和纳入规则后复用方法；通用元数据处理优先使用 `citation-management`。历史脚本保留原位不改写：

1. `collect_foreigner_landscape.py` — 搜索采集：title-focused OpenAlex 查询 → 保留全部候选 → 透明过滤 → work ID 去重 → 输出 SEED 集
2. `build_china_inbound_migration_litdb.py` — 富集与分级：SEED → works API 补全 → 硬排除 → 分级 → 主题/方法分类 → 证据等级与置信度 → 项目字段 CSV
3. `assemble_china_inbound_migration_litdb.py` — 汇编：学术记录 + 策展灰色文献 register + 人工核验记录 → 去重 → 保留排除决策 → 最终 register

### B1. 检索（SEED 集）

- OpenAlex API，query 列表围绕研究问题展开（如 "immigration to China" / "foreigners in China" / …），**title-focused**：搜索命中数不等于文献数量，只以题名匹配作为候选边界
- 规范 User-Agent：`{项目名}/1.0 (mailto:{你的邮箱})` —— 使用已授权的真实联系信息；运行前以当前官方 API 文档核对访问、认证与速率要求，不填虚构邮箱
- 保留全部候选写入 `openalex-candidates-*.csv`，不在采集阶段丢弃任何记录

### B2. 分级

对每条候选按题名（权重最高）与摘要判定状态，状态和理由都必须落库：

| 状态 | 含义 |
|------|------|
| `CORE` | 题名明确指向目标问题/人群 |
| `PERIPHERAL` | 方向由摘要确认，题名边界弱 |
| `EXCLUDED` | 命中排除词典（见下） |
| `POLICY_CONTEXT` | 制度/统计/灰色文献背景记录 |

排除词典按类组织（参考实现里的 `HARD_EXCLUDE`）：方向相反类（如研究"移入中国"时排除"中国学生出国"）、历史/地理错配类、非人类/模型噪声类（cell migration、mathematical modeling）。每类排除给出理由字符串。

### B3. 富集

对每条 SEED 调 `https://api.openalex.org/works/{id}`，补全：

- 摘要：OpenAlex 的 `abstract_inverted_index` 是倒排索引，需还原为顺序文本（参考 `reconstruct_abstract`）
- 发现摘录：从摘要中挑 RESULTS/FINDINGS 标记句，截 420 字符——这是发现线索，不是已完成原文核验的证据，须注明"来自 OpenAlex 所收摘要，以原文为准"
- 作者、机构、机构国家：注意机构 ≠ 国籍，**禁止用作者名推断国籍**
- 主题分类：按项目定义的主题词典打分（题名命中 ×5 + 摘要命中 ×1），取最高分作一级主题，次高分作次级主题
- 方法分类：按方法词典匹配（系统综述/民族志/定性访谈/问卷/纵向/政策文本/话语/空间/实验/回顾数据）
- 样本量：正则提取 `N=…` / `… participants` 等模式

### B4. 证据等级与置信度

| 字段 | 规则 |
|------|------|
| 证据等级 | DOI 只标识对象，不证明同行评议或质量。按来源类型、版本与已核验出版信息记录；未核验则写 `出版类型/同行评议状态待核` |
| 纳入置信度 | 记录纳入理由和依据；CORE/PERIPHERAL 表示相关性，不等于研究质量，不自动转换为概率或质量分数 |
| 证据基础 | 有摘要 → `OpenAlex摘要`；无摘要 → `仅元数据，须全文复核` |

### B5. 汇编与产出

下面是历史 register 的 35 列 schema 示例。新项目按问题保留必要字段，不要求填满所有列；无法核验的值保持缺失并注明原因：

`数据库ID, 来源记录ID, 记录状态, 状态理由, 数据来源流, 出版日期, 年份, 原题名, 中文题名, 语言, 作者, 作者机构, 机构国家/地区, 来源类型, 来源大类, 发布主体大类, 期刊/发布机构, 一级主题, 次级主题, 研究人群, 地理范围, 方法, 样本量, 中文主要发现, 原文发现摘录, 证据基础, 证据等级, 纳入置信度, DOI, 来源URL, OpenAlex ID, 被引数快照, 开放获取, 访问日期, 备注`

配套产出：

- `academic-corpus-2020-2026.csv` — 全量分级语料
- `literature-register-*.csv` — 最终登记表（排序：状态 → 年份倒序 → 题名）
- `summary.json` — 状态分布、年份分布、语言、主题分布统计
- 排除与去重决策**全部保留**——数据库可审计是这条管线的核心价值

## 与下游 skill 的衔接

- 检索结果直接作为 **medium-research-report-harness** 的证据轨输入（来源登记表与检索日志正是该 harness 的消费对象）——两者分工：本 skill 生产文献资产，harness 消费它写报告
- 值得深读的单篇文献 → 交给 **706-long-article-distilling** 做八段式蒸馏入库
- 引用元数据、BibTeX 与去重 → **citation-management**；研究主张与方法批判 → **scientific-critical-thinking**
- 判断学术关注度趋势须有可比年度检索口径、数据库覆盖与去重说明；精选时间线只提供线索

## 方法原则

保留可审计性，并按研究问题调整历史方法：

1. **显式检索边界**——题名限定适合聚焦检索；是否扩展摘要/主题词取决于召回需求。搜索命中数不是有效文献数量
2. **候选全保留**——采集阶段不丢记录，丢弃只发生在有理由的分级阶段
3. **排除留痕**——每条 EXCLUDED 都带理由，决策可复查
4. **机构 ≠ 国籍**——绝不从作者名推断国籍
5. **覆盖不自称穷尽**——OpenAlex 覆盖有边界，中文文献需 WebSearch/CNKI 补充轮
6. **摘要摘录标注来源**——发现摘录一律注明来自摘要，需以原文为准

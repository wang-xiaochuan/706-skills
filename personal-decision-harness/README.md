# 个人判断系统 · 最小版 v0.1

这是一个能在对话中运行的 skill。目标是完成当前取舍，同时练习寻找信息、分析信息和建立判断。

## 开始使用

对 Codex 说：

> 使用 $personal-decision-harness。我在考虑……我目前倾向于……因为……

也可以说：

> 用个人判断系统，帮我安排这一周。我可用的时间是……候选事情有……

> 回看这条决策：[记录路径]，实际结果是……

若新 skill 尚未出现在当前会话的可用列表，直接说“读取 $706_LOCAL/706-skills/personal-decision-harness/SKILL.md 并按它运行”，或在新会话中调用。不保证当前会话热加载。

不用先填长问卷。系统会在真实决策中逐步补齐底稿，只追问会影响当前结论的信息。你可以说“快速判断”“深入分析”“这次不保存”或“跳过练习”。

## 文件

- SKILL.md：流程、输出、证据与续接规则。
- templates/：底稿、决策卡、每周取舍和回看模板。
- data/profile.md：你的本地底稿；目前只录入本次对话明确确认的职业方向，其他待补。
- data/decisions/：真实决策与追加回看。
- data/weeks/：每周取舍。
- evals/evals.json：虚构检查案例，不是你的真实经历。
- VALIDATION.md：本版验证范围与限制。

## 存储与搬运

本文件夹是权威源，Codex 安装入口是 ~/.codex/skills/personal-decision-harness 的符号链接。无需服务器或 API 密钥；检索由当前助手可用工具承担。

data/ 已被忽略并设置本机私有权限，但没有加密。分享或打包时排除整个 data/。仅迁移供自己使用时才连同 data/ 搬运，随后修复安装链接。新安装若没有 data/，按 templates/profile.md 初始化，不能带入本用户的个人资料。

## 完成的定义

第一版具备单次判断、每周取舍、回看和本地记录能力。尚未经过真实决策结果的长期验证；模拟检查不代表判断准确率，也不代表已经提高了个人能力。

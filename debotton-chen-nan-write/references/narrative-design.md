# 叙事设计与写作简报参考

按当前阶段选读。此文件提供判断维度与模板；执行范围、审核点和并行方式以 SKILL.md 为准。

## 叙事品味准则

这些准则是贯穿所有阶段的**审美罗盘**。不是操作步骤，而是在 方案阶段 生成方案和 大纲阶段 细化大纲时必须对照的默认质地标准。

### 审美维度

- **反感动**：不让叙事试图"制造"读者的情绪反应。让事实、物件、场景自己传递，读者自己感受到的才是真实的。
- **反结论**：不把事件包装成一个干净的道理或教训。复杂性是终点，不是需要被克服的障碍。
- **反英雄**：不制造全知全能的"主角叙事"。承认事件中每个人都有局限，没有人完整地理解全局。
- **正具体**：一个具体的物件或画面，重量永远大于一段抽象概括。叙事要在具体物上着陆。
- **正沉默**：什么没有说、什么缺席、什么被回避——往往比说出来的更有信息量。
- **正矛盾**：保留矛盾不解决，比强加一个和解更诚实。好的叙事让矛盾"在那里"。
- **在场感**：叙事者有一个具体的观察位置，不是全知的上帝视角。
- **距离感**：保持人类学家式的克制凝视，不急于融入、不急于评判
- **正安静**：让事实和画面自己传递重量，不用"惊人的""前所未有的""比任何……都……"替读者做判断。好的观察不需要被放大——它静静地在那里，就已经够了。

### 本体维度

详见 `voice-profile.md §十 本体品味`。10 个维度：
Agency / Temporality / What is real / Causality / Scale / Negative space / Epistemic humility / Moral frame / Human & non-human / The unsayable

叙事方案和 outline 都需要对照这 10 个维度自查。本体品味不是"加分项"，是叙事质地的基础判断。

## 反身性要求

回顾文不是报道，不是总结。回顾文需要提供一种**反身性视角**——不只是叙述"发生了什么"，更要回答四层问题。这四层不是单独的章节，它们应该**贯穿全文**，在每一节的叙述中同时运行。

### 1. 我们的角色是什么？

我们在事件中的位置——不是中立的旁观者，不是全知的评论者，是一个有具体位置的参与者。这个位置本身需要被叙述：我们是组织者还是参与者？我们"站在旁边"还是"站在中间"？我们有什么没做到的？我们的存在本身改变了现场的什么？

自查：文章里有没有一段话让读者感知到"叙述者是一个具体的人/团队，有一个具体的立场和局限"？

### 2. 这个事件在更大的话语场中意味着什么？

不是宏大叙事（"这标志着……"），而是具体的分析。这件事折射出了什么技术和人的关系？它和正在发生的更大的讨论（AI 加速、青年文化、社群组织方式）之间有什么连接？它在回应什么沉默？它在制造什么新的问题？

自查：文章有没有在某个点从"这件事"跳到了"这背后是什么"？跳得是不是太用力了？

### 3. 对不在场的人有什么意义？

回顾文的读者大部分没有参与这个事件。文章需要回答"我为什么要读这个"——不是通过煽情或制造 FOMO，而是通过提供可以迁移的观察、问题或形式。读者能从这个活动中带走什么到自己正在做的事情里？

自查：文章里有没有一句话是"你下次也可以试试"或"你身边可能也有这样的事"——哪怕没写出来，读者能不能隐约感觉到？

### 4. 诚实面对局限

我们没做到什么？我们回避了什么？我们的观察有什么盲区？反身性不是自我表扬，是诚实地审视自己的位置——包括那些不方便说的话（我们划了什么边界？谁没有被邀请？哪一刻我们失败了？）。

自查：文章里有没有至少一个地方是"这里我们没做好"或"这个我不知道"？还是从头到尾全是正确的？

### 反身性在 outline 中的落地

在 大纲阶段 生成每一节大纲时，必须标注：这一节的反身性维度是什么？——是对 706 角色的反思、是对大话语场的连接、是对读者的迁移提示、还是对局限的诚实？

## 材料理解与研究简报

退一步，看事件的底层性质：

- 这个活动 / 项目的**本质是什么**？（论坛？实验？仪式？表演？偶遇？转折？）
- 它处于什么样的**生态系统**中？（社区生命周期、产业阶段、话语场域）
- **关键角色**是谁？他们之间的关系是什么？权力/知识/情感的分布？
- **利害关系**是什么——显性的和隐性的？
- 这个事件运作在什么**默认假设**之下？（什么被认为是理所当然的？）
- 它属于什么样的**历史/文化脉络**？

**内部产出**：元分析简报（3–5 段话），捕捉大局理解。这将成为后续叙事提案的基石。

---

### Phase 3：情境调研（Situation Research）

从抽象退回具体，细致绘制事件本身：

- **时间线**：关键节点、转折时刻、前后的反差
- **空间**：物理或虚拟场地、氛围、动线、布局
- **人物**：谁在场、谁发言、谁沉默、谁受到影响、谁处在边缘
- **内容**：说了什么、展示了什么、表演了什么、创造了什么
- **交互**：摩擦、共鸣、误会、同盟、回避的瞬间
- **物质痕迹**：物件、幻灯片、文件、图像、直接引语

**内部产出**：情境地图——详细的事实清单，按上述维度组织。这是后续所有叙事选择的素材库。

---

### Phase 4：张力分析（Nuance Analysis）

这是洞察发生的地方。审视素材中：

- **张力与矛盾**：什么在冲突？什么不合逻辑？什么具有反讽意味？
- **症候性细节**：什么微小瞬间或物件携带了更大真相？
- **未言明之物**：什么被显眼地缺席？什么被暗示但从未说出？
- **情绪底流**：现场的真实氛围是什么？在哪一刻发生了变化？
- **道德/伦理问题**：什么令人不安？什么令人动容？什么是复杂的？
- **意外关联**：看似无关的元素之间藏着什么连接？

**内部产出**：张力报告——关键洞察、叙事钩子、情感支点。

---

### Phase 5：研究简报（Research Brief）· 文件产出

将 Phase 2–4 的内部分析（元分析 + 情境调研 + 张力分析）整合为一份 **研究简报**。简报是整个叙事设计的素材基础。

**研究简报格式**：

```
# 研究简报：《Event Title》

## 1. 事件本质与生态系统
[从元分析中提取的核心判断：这个事件是什么性质的？处于什么生态中？]

## 2. 关键事实与素材库
### 时间线
[关键节点、转折时刻、时间密度变化]
### 人物
[核心人物列表：姓名/身份/角色/关系/谁缺席]
### 空间与物件
[场地描述、关键物件、非人行动者]
### 关键引语
[逐字引语，标注说话人、时间、场合]
### 关键数字
[人数、时长、规模等]

## 3. 张力与洞察
### 核心张力
[矛盾、悖论、未解决的冲突]
### 症候性细节
[微小但携带大信息的瞬间]
### 缺席与沉默
[谁没来、什么没说、什么被回避]
### 情绪底流
[氛围变化、情感高点、未释放的紧张]

## 4. 叙事钩子
[初步识别的 3–5 个叙事线索，供后续叙事方案设计用]
```

**输出**：将研究简报写入项目目录的 md 文件（如 `research-brief-v1.md`）。

## 叙事选项

#### 6A. 生成方案

基于研究简报中的所有素材，生成 **2–4 个不同的叙事框架**。每一个都是讲述同一个事件的不同方式。

#### 6B. 品味过滤

对每个提案，对照叙事品味准则逐条筛查：

**审美筛查**：
- 是不是太显然了？（如果一句话就能猜出全文走向，深度不足——淘汰或重写）
- 是不是在制造感动？（如果叙事本身在"要求"读者产生某种情绪，是品味失败）
- 有没有留下未解决的张力？（全部闭合、干净收束的叙事是可疑的）
- 是否选对了锚点？（锚点是具体物/画面，还是抽象道理？）

**本体筛查**（对照 voice-profile.md §十 的 10 个维度）：
- 为每个提案标注其在 10 个维度上的**优势**（哪个维度天然强）和**盲区**（哪个维度被忽视）
- 盲区不一定是致命伤——有些维度在某些叙事方向中不需要是主角。但必须在呈现时标注

不通过筛选的选项要么淘汰、要么在呈现时明确标注风险。

#### 6C. 呈现给用户

对每个方案，提供：

| 维度 | 说明 |
|---|---|
| **一句话概括** | 这个叙事角度的核心是什么 |
| **核心命题** | 这篇文章真正在讲什么事？（1–2 句） |
| **情感弧线** | 读者经历什么感受？起点 → 中段 → 终点 |
| **视角** | 从谁的眼中看见？站在什么位置观察？ |
| **关键意象** | 贯穿全文的重复图像、物件、或主题 |
| **结构提示** | 章节大致如何流动？叙事节奏怎样？ |
| **语调** | 追忆的？调查的？庆祝的？反讽的？私密的？ |
| **品味评估** | 亮点（哪些维度强）+ 风险（哪些维度弱，会导致什么问题） |

## 详细大纲

用户选定（或结合）叙事方向后，产出逐节大纲。

**逐节品味检查**：在写每一节大纲时，对照以下问题：
- 这一节有没有至少一个**具体的物或画面**，而不是纯叙事/纯信息？
- 节奏有没有**留白**？还是填得太满？
- 这一节是"搭建经验"还是"交代信息"？如果是后者，需要重新设计
- 这一节有没有制造"圆满感"的冲动？有没有给不确定留空间？

对每一节，给出：

```
### 第 N 节：[标题 / 功能描述]
- 叙事意图：这一节在整个弧线中起什么作用？
- 核心内容：必须包含的具体事实、人物、场景、引语
- 语调与节奏：快还是慢？密集还是疏朗？什么情绪基调？
- 与前节的衔接：如何承接上一节的落点？
- 为后节做铺垫：埋下什么伏笔或转向？
- 声口提示（选填）：给下游写作 skill 的指引，例如"此处适合 G. Commentary 模板：Context 起句 → Perspective 浮现 → Relationship 在场"
- 品味自查：这一节的审美风险？（平铺直叙 / 说教 / 制造感动 / 填太满 / 没有具体物）
- 反身性维度：这一节在四层反身性中的哪一层或哪几层？（706 角色反思 / 大话语场连接 / 对读者的迁移 / 局限诚实）
```

**整篇还需附带：**
- **开篇策略**：以什么 frame、意象或问题开头
- **收尾策略**：以什么画面、反应或悬而未决的想法结束（收尾不制造"圆满感"——留一个具体的、悬在空中的东西）
- **事实复核清单**：所有必须写入的人名、数字、引言、地点
- **风险提示**：哪些位置可能变得平铺直叙、说教或混乱，如何规避
- **整体品味复核**：对照 voice-profile.md §十 的 10 个本体维度，标注整篇 outline 的优势维度与盲区
- **整体反身性复核**：贯穿全文的四条反身性线索是否都落地了？有没有某一层被遗忘？

**输出**：将详细大纲写入项目目录的 md 文件（如 `outline-v1.md`）。

## 写作简报模板

```
### 板块 N：[标题]

叙事意图
[一句话 —— 这一节在全文弧线中起什么作用]

核心内容
- [点 1]：[具体展开，包含人物、引语、场景、数据]
- [点 2]：[同上]
- [点 3–5]：[同上]

必用引语（逐字）
- "[引语全文]" —— [说话人 · 场合]

必写画面
- [具体的场景/物件/身体时刻 —— 不能是抽象描述]

声口模板
[A–G 中的哪一个，如 "G. Commentary" 或 "B. 调查叙事"]

反身性锚定
[这一节在四层反身性中的位置和具体落点]

字数
~X 字
```

**简报原则**：
- 每一条"核心内容"都可以被直接写成段落——人名、引语、数字、场景全部在场
- "必用引语"是逐字的、完整的、标注了说话人和场合的
- "必写画面"是具体的——"铁丝网上系满了彩色毛线"而不是"装置互动很活跃"
- 简报不拼入大纲文档，单独呈现

# Narrative Crafting（活动与项目回顾）

从可追溯素材中建立叙事，再按用户需要产出大纲或全文。保留 706 的具体、克制、在场感与反身性：不制造感动、英雄或圆满结论，不把推测写成现场事实。

## 先确定已有进度

- 新长文先检查材料、给出简要计划与结构。用户只要计划或方案时，交付到这一层。
- 已有学习笔记、选定方向或确认大纲时，从对应阶段继续，不重做已经完成的准备。
- 用户要求逐阶段打磨时，在约定的选择点等待。用户要求直接成文、已经选定方向或授权自主推进时，完成必要准备后继续，不增加研究简报、大纲、写作简报三次重复审核。
- 单节改写或事实修正只处理相关内容和受影响的衔接；只有整体方向变化才回到叙事方案。

## 素材与叙事

1. 阅读提供的材料，保留来源索引。可使用已有 prewriting 笔记；关键引语、人名、数字与冲突回到原始记录核验。复杂素材可按需调用 prewriting，不把它作为所有文章的前置步骤。
2. 形成事实清单与核心张力，区分观察、解释、缺口。背景事实需要时再检索；不得补造现场对白、身体语言或他人动机。
3. 方向尚不清楚时给出有区别的叙事选项及各自证据依据。已有方向则直接形成大纲；结构与素材有关键冲突时说明原因，先完成不依赖该决定的工作。
4. 大纲说明每节功能、具体素材、前后衔接及全文的反身性。材料有限时缩小论断，不强行让每节填满全部理论维度。

设计长文时按需读取 [narrative-design.md](references/narrative-design.md)：其中保留审美与本体维度、四层反身性、研究简报和大纲模板。不要默认把所有模板都变成独立交付物。

## 写作

延续本技能既有的德波顿（陈广兴／南治国译）默认声口；用户指定的文体和语气优先。实际写作或声口修改前读取 [voice-profile.md](references/voice-profile.md) 中适用部分，事实核对不需要加载整份声口档案。

为需要成文的板块准备足够具体的建材：人名、数字、逐字引语、场景、来源定位、叙事功能与字数范围。简报可在现有大纲中展开；用户没有要求时不另设审核文件。

依文章的整体连贯性决定执行方式。短文、单节修订或相互依赖强的叙事由主代理完成。材料或章节可以独立处理、当前环境允许且能带来实际收益时，使用可调用的协作工具委派；不按章节数强制一章一个代理，也不指定不存在的工具名。

委派时给每项工作明确范围、完整材料和统一声口，避免重复读取；主代理保留全文结构、跨节事实与衔接责任。整合和复核可以由主代理完成，不必须额外启动“缝合代理”。

## 验收与交付

- 按原文核对关键人名、数字、引语及其说话人；列明仍未核实的关键缺口。
- 检查全文叙述人称、节奏、衔接与具体细节，应用选定声口的检查规则；不为了填满模板编造事实或额外结论。
- 在原项目合适位置保存用户所需的研究简报、大纲或草稿；版本与路径明确，修订不覆盖用户指定保留的版本。
- 成文是草稿交付，实际对外发布另按已有授权与发布工具要求处理。只完成一个阶段时如实标注，不声称全流程完成。

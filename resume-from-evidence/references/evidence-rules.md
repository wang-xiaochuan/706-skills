# 聊天到事实的规则

## 两个独立维度

“谁说的”与“事实发生到什么程度”不要塞进同一个可信度标签。

**来源支持**：材料支持／本人明确确认／估算／待核实／冲突／无依据。材料支持需注明材料究竟证明了什么，文件存在不证明内容正确。旧简历也是自述材料，不自动升级为独立证实。

**归属与状态**：个人／团队或组织；计划／进行中／已产出／已使用／已公开。工具生成文件只支持已产出；本地运行只支持本地验证；用户使用需使用记录；公开上线需发布证据。

## 使用规则

| 输入 | 可做什么 | 不能做什么 |
|---|---|---|
| 用户：想转产品，希望做用户研究 | 记录方向意愿，询问做过的研究案例 | 写“资深用户研究专家” |
| AI：建议开展十场访谈 | 列为行动建议 | 写“完成十场访谈” |
| 用户：我实际访谈了三人，记录在附件 | 提取记录，确认个人动作和产出 | 自动推为代表性市场结论 |
| AI：项目已上线；工具日志只有本地构建 | 保留本地原型表述，追查部署证据 | 写“已上线服务客户” |
| 活动报道：有 800 人；用户：我协调了四位讲师 | 可写本人协调四位讲师；整体规模另标项目背景 | 写“独立招募并运营 800 人” |
| 旧稿写负责人；本人纠正只是协作 | 更新事实库，采用协作角色 | 用“最新版”继续保留负责人 |

## 数字与冲突

每个数字保留单位、时间窗口、总体／样本、个人／组织、实测／估算和来源。百分比需要分子分母、基线和对比时期；不从“方便很多”推断“效率提升 50%”。重复出现在多份简历中的同一数字仍可能只有一个来源。

把矛盾的说法和出处并列，优先处理高影响事实。缺少精确月份时可保留有依据的年份，但不能自行补月份消除时间空档；兼职重叠按真实任职关系说明。本人明确纠正的事实记入变更记录，不让旧稿重新覆盖。

## 隐私与材料范围

优先让使用者挑选与工作相关的聊天片段。跨会话历史读取只限授权范围，无法访问时说明，不声称记得未读取内容。私人健康、关系、他人联系方式等通常与简历无关，不写进经历库或共享示例。

涉及保密工作时，使用经过允许的机构类别与职责概括。证据底稿本身也可能敏感，不能因为简历匿名化就把底稿放进公开作品集。建议新做公共资料作品时，单列计划，完成前不写成果。

# 项目学习笔记模板

```
# 项目学习笔记：《Event/Project Name》

---

## 1. 人物档案（维度 01）
- 完整名单：姓名 / 身份 / 角色 / 在场位置
- 关系图谱：谁与谁对话、谁与谁不在同一空间
- 发言 vs. 沉默：谁在讲台上，谁在私下，谁缺席
- 叙事可用标签：每一条标注 → 可用于什么（人物速写 / 张力 / 对比）

## 2. 时间线（维度 02）
- 正式时间线：议程节点
- 实际时间线：延迟、加速、意外的间隙
- 情感时间线：什么时候紧张了、什么时候松了
- 时间密度变化点：哪个瞬间"变慢了"
- Before / After 反差

## 3. 话语记录（维度 03）
- 逐字引语清单（标记来源、时间点、说话人）
- 主题地图：被讨论的关键词和框架
- 回避带：被显眼地没有讨论的话题
- 话语权力分布：谁定义术语、谁在使用、谁在沉默

## 4. 物与空间（维度 04）
- 空间描述：动线、尺度、氛围、物理布局
- 物件清单：设备、道具、印刷品、残留物
- 非人事件：投影仪坏了、空调太冷、外面下雨、白板上的旧笔迹

## 5. 情感地形（维度 05）
- 情绪高点：什么时候最投入？什么时候最尴尬？
- 身体语言记录：姿势、移动、眼神
- 氛围转换点：什么改变了房间的空气？
- 不解释为什么，只记录什么发生了

## 6. 组织与结构（维度 06）
- 活动格式与流程设计
- 幕后人：谁在组织？谁在做琐事？
- 资源与限制：预算 / 场地 / 时间 / 人力
- 意外与应对：计划外发生的事和组织反应

## 7. 背景上下文（维度 07）
- 历史关联：之前发生过什么相关的？
- 领域语境：这个议题在更大范围内处于什么位置？
- 平行参照：同期发生的其他相关事件
- 既有文本：之前写过的相关文章 / 报告 / 文档

## 8. 品味维度审查（维度 08）
- 对照 10 个本体维度（Agency / Temporality / What is real / Causality / Scale / Negative space / Epistemic humility / Moral frame / Human & non-human / The unsayable）
- 逐维度标注：数据中天然支持了什么？什么维度严重缺失？

## 9. 数字与数据（维度 09）
- 人数 / 时长 / 金额 / 规模 / 频次 / 比例
- 所有可量化信息的穷尽清单
- 标注数据来源和可信度

## 10. 对齐报告（维度 10）
### 交叉验证
- 信息一致点：多个独立来源一致支持的事实（同一材料的重复提取不算独立证据）
- 信息矛盾点：不同来源对同一事件的冲突描述
### 叙事富矿标注
- 信息高密度交叉点：[位置/时刻] → 多个维度信息汇聚，叙事潜力最高
### 本体维度盲区
- [维度名]：全量数据中几乎空白，叙事设计时需注意
### 缺口与待确认
- 确定缺失：
- 推断但不确认：
- 需向用户确认：

---

覆盖范围、未读材料与待确认项：按实际检查结果填写。
```
